# Figure QA

- Backend: Python only (Matplotlib)
- Figure archetype: quantitative comparison
- Final canvas: 150 × 88 mm before tight bounding-box trimming
- Primary format: SVG with editable text
- Companions: PDF, 600 dpi TIFF, 300 dpi PNG
- Statistics: observed proportions; n = 8 per task and n = 56 overall
- Color semantics: reference-matched green = complete success; blue = moderate/high performance;
  light orange = weakest task; deeper blue = supplied overall result. Yellow is not used.
- Accessibility: position and direct numeric labels carry the values independently of color
- Data handling: task-level and overall values reproduce the supplied table directly
